You only need this endpoint to set the primary key up front. Adding documents to an index that does not exist creates it for you. Requires an admin key.

## Body

<ParamField name="uid" type="string" required>
  The name of the index. Lowercase letters, numbers, hyphens and underscores, up to 64 characters.
</ParamField>
<ParamField name="primaryKey" type="string" default="id">
  The field that uniquely identifies each document. It cannot be changed once the index has documents.
</ParamField>

## Errors

<ResponseField name="index_already_exists" type="409">
  An index with this uid already exists.
</ResponseField>
<ResponseField name="invalid_request" type="400">
  The uid has characters that are not allowed.
</ResponseField>
