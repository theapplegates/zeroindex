Build the new version in a separate index, then swap. Searches move over in one step, so users never see empty or half imported results. See [Syncing a database](/docs/guides/syncing-a-database). Requires an admin key.

## Body

<ParamField name="[].indexes" type="string[2]" required>
  The two indexes to swap. Send several pairs to swap them all in one task.
</ParamField>

<Callout type="note">
  Both indexes must exist. After the swap, the second index holds the old documents, so you can swap back if something is wrong.
</Callout>
