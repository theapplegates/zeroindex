A document whose primary key does not exist yet is added as sent. Requires an admin key.

## Path parameters

<ParamField name="uid" type="string" required>
  The name of the index.
</ParamField>

## Body

<ParamField name="[].id" type="string | integer" required>
  The primary key of the document to update.
</ParamField>
<ParamField name="[].*" type="any">
  The fields to change. Send `null` to remove a field.
</ParamField>

<Callout type="tip">
  Updating a price or a stock count is the most common write in a shop. Send only those fields, and the request stays small even for thousands of products.
</Callout>
