Keys are shown shortened. The full key is only returned once, when you create it. Requires an admin key.

## Response

<ResponseField name="results[].uid" type="string">
  The id of the key, used to delete it.
</ResponseField>
<ResponseField name="results[].kind" type="admin | search">
  What the key can do.
</ResponseField>
<ResponseField name="results[].indexes" type="string[]">
  The indexes the key can reach. `*` means every index.
</ResponseField>
<ResponseField name="results[].lastUsedAt" type="string | null">
  When the key last made a request. Useful to find keys that are safe to revoke.
</ResponseField>
