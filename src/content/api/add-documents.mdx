If the index does not exist, it is created with the default settings. Requires an admin key.

## Path parameters

<ParamField name="uid" type="string" required>
  The name of the index.
</ParamField>

## Body

An array of documents, up to 1,000 documents or 10 MB per request.

<ParamField name="[].id" type="string | integer" required>
  The primary key. Use the field name you chose for the index if it is not `id`.
</ParamField>
<ParamField name="[].*" type="any">
  Any other fields. Nested objects are flattened, so `dimensions.width` becomes its own field.
</ParamField>

## Errors

<ResponseField name="payload_too_large" type="413">
  The request is over 10 MB. Split the documents into smaller batches.
</ResponseField>
<ResponseField name="invalid_request" type="400">
  The body is not an array, or a document has no primary key.
</ResponseField>
