Only the settings you send change. The index is rebuilt in the background, and searches use the old settings until the new ones are ready. Requires an admin key.

## Path parameters

<ParamField name="uid" type="string" required>
  The name of the index.
</ParamField>

## Body

<ParamField name="searchableAttributes" type="string[]">
  The fields queries match against, most important first. Send `["*"]` to search every field.
</ParamField>
<ParamField name="filterableAttributes" type="string[]">
  The fields you can use in filters and facets.
</ParamField>
<ParamField name="sortableAttributes" type="string[]">
  The fields you can sort results by.
</ParamField>
<ParamField name="rankingRules" type="string[]">
  The order of the ranking rules. See [Ranking](/docs/concepts/ranking).
</ParamField>
<ParamField name="synonyms" type="object">
  Words that should match each other, like `{ "phone": ["mobile", "cell"] }`.
</ParamField>
<ParamField name="typoTolerance" type="object">
  Word lengths for one and two typos, and fields where typos are turned off.
</ParamField>
