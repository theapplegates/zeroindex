Indexes are sorted by name. Requires an admin key.

## Query parameters

<ParamField name="limit" type="integer" default="20">
  How many indexes to return, from 1 to 100.
</ParamField>
<ParamField name="offset" type="integer" default="0">
  How many indexes to skip.
</ParamField>

## Response

<ResponseField name="results" type="Index[]">
  The indexes on this page.
</ResponseField>
<ResponseField name="results[].uid" type="string">
  The name of the index.
</ResponseField>
<ResponseField name="results[].primaryKey" type="string">
  The field that identifies each document.
</ResponseField>
<ResponseField name="results[].numberOfDocuments" type="integer">
  How many documents the index holds.
</ResponseField>
<ResponseField name="total" type="integer">
  How many indexes the project has in total.
</ResponseField>
