Deleting a document that does not exist still succeeds, so you can safely retry. Requires an admin key.

## Path parameters

<ParamField name="uid" type="string" required>
  The name of the index.
</ParamField>
<ParamField name="id" type="string | integer" required>
  The primary key of the document to delete.
</ParamField>

<Callout type="note">
  To delete many documents at once, send `POST /v1/indexes/{uid}/documents/delete` with a list of ids or a filter.
</Callout>
